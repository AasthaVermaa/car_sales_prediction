# Car Sales Prediction Using Linear Regression

## Project Overview
This project uses Linear Regression to analyze car sales data and explore the factors that influence vehicle sales. The goal is to build and evaluate regression models and understand their predictive performance.

## Objectives
- Perform data preprocessing and exploratory analysis.
- Identify relevant features for predicting car sales.
- Build and compare Linear Regression models.
- Evaluate model performance using appropriate regression metrics.
- Identify limitations and potential improvements.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas and NumPy
- Statsmodels
- Scikit-learn
- Matplotlib and Seaborn (where used)

## Methodology
1. Data preparation and preprocessing.
2. Feature analysis and selection.
3. Multicollinearity assessment using Variance Inflation Factor (VIF).
4. Development of baseline and regression models.
5. Evaluation using metrics such as MAE, RMSE, and R².
6. Interpretation of results and model limitations.

## Key Learnings
- Feature selection can significantly affect model performance.
- Training performance does not necessarily translate into good test performance.
- Regression diagnostics and evaluation are important when interpreting results.
- Dataset quality, sample size, and model assumptions can influence predictive accuracy.

## Limitations
The models may not generalize well to unseen data. Further work could include reviewing outliers, checking regression assumptions, testing alternative feature combinations, and evaluating additional data.

## Project File
- `car_sales_prediction.ipynb` — Notebook containing the analysis, model development, and evaluation.

## How to Run
1. Download or clone this repository.
